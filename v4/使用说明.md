# TIFF 双向转换工具 V4

Windows 10/11 64 位；运行安装程序，选择安装位置；或解压便携包后双击程序。无需安装 Python 或许可证。安装程序只创建所选程序文件夹，不创建开始菜单或卸载项；需要移除时关闭软件后删除该程序文件夹。启动后在顶部选择转换方向：

- **普通 TIFF → BigTIFF**：将 TIFF 42 写成 BigTIFF 43；可用于把此前本工具转换的普通 TIFF 重建为 BigTIFF。
- **BigTIFF → 普通 TIFF**：将 TIFF 43 写成普通 TIFF 42；输出受经典 TIFF 约 4 GiB 的寻址限制。

选择文件或文件夹，选择输出/PDF 文件夹，然后开始转换。每次操作生成一份 PDF；单个文件失败会记录原因并继续其余任务。默认生成独立副本。勾选原位替换后，程序验证输出、再次核对源文件，再将原文件保存为同目录 `.original-backup` 备份并替换原路径；备份路径写入报告。遇到系统或存储故障时应检查源路径和备份。

转换直接复制图像块并验证数据哈希、非结构标签、图像块长度及格式。不同 TIFF 容器需要重写文件头和目录偏移，输出不会与历史文件逐字节相同。输入已经丢失的标签、颜色或影像数据无法靠容器转换恢复。专有标签若包含本工具无法识别的内部指针，需以目标软件验证。对无法安全识别的 TIFF 结构，程序会报错并停止该文件。

历史样本已经比较过图像块、非偏移标签和坐标信息；Leica HxMap 的打开与项目验收尚需在目标软件中进行。

## 源码启动

安装仓库根目录的依赖后运行 `python v4\app.py`。命令行示例：

```powershell
python v4\app.py input.tif --direction to_big --output-dir output
python v4\app.py --folder input-folder --recursive --direction to_classic --output-dir output
```
