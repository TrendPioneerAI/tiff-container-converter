# 影像格式转换 V5.2

Windows 10/11 64 位，离线运行。完整解压便携包并双击程序，或运行安装程序后启动，无需 Python 或许可证。选择转换方向、文件或文件夹及输出目录，开始后生成 PDF 核验报告。

- **TM → YS**：选择一张目标格式的 YS 参考图，按其结构和文件大小输出。使用精简标签、单位像素坐标，默认将 0 标记为 NoData；逐像素验证。不支持的结构、参考参数或文件大小不一致时拒绝输出。
- **转 BigTIFF**：将受支持的普通 TIFF 重排为 256×256 瓦片 BigTIFF，逐像素回读验证。仅支持单页、无压缩、RGB 每通道 8 位、交错排列、每行一条带及部分可识别的 TIFF/EXIF 标签。
- **转普通 TIFF**：将 BigTIFF 转为普通 TIFF，保留受支持的图像块组织。输出受普通 TIFF 的 4 GiB 寻址限制。

瓦片模式只生成新文件，无法替换输入。BigTIFF 瓦片模式保留输入中受支持的非结构性标签和 EXIF 项；对于不支持的指针结构明确拒绝。某些应用未必能读取 BigTIFF 中的 EXIF，目标软件须实际验证。输入中已缺失的数据无法恢复。文件大小相近不表示与历史文件逐字节相同。请先用少量文件测试，并保存输入原件。

普通 TIFF 瓦片模式按精简格式生成，不保留输入中的 Photoshop、XMP、IPTC、EXIF 等编辑标签；带地理定位标签的输入会拒绝处理。单位像素坐标用于像素空间，不是地理坐标系。NoData 会影响应用对数值 0 的显示和统计，原像素数值不改变。

命令行可使用 `--direction to_big_tiled`，需要 `--output-dir`。原有 `to_big` 仍可通过命令行使用。生成的报告包含本机文件路径和校验值，应由使用者本地保管。

普通 TIFF 瓦片模式使用 `--direction to_classic_tiled --reference 参考.tif --nodata-zero --output-dir 目录`。输出与参考文件大小和结构一致，像素来自输入文件。
