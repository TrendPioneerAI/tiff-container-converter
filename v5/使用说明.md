# TIFF 双向转换工具 V5

Windows 10/11 64 位，离线运行。完整解压便携包并双击程序，或运行安装程序后启动，无需 Python 或许可证。选择转换方向、文件或文件夹及输出目录，开始后生成 PDF 核验报告。

- 普通 TIFF → BigTIFF、BigTIFF → 普通 TIFF：保留受支持的图像块组织；沿用原有安全限制。
- 普通 TIFF → 256瓦片 BigTIFF：重排为 256×256 瓦片，逐像素回读验证；仅支持单页、无压缩、RGB 每通道 8 位、交错排列、每行一条带及部分可安全识别的 TIFF/EXIF 标签。遇到不支持的结构会记录失败并继续下一个文件。

瓦片模式只生成新文件，无法替换输入。转换保留输入中受支持的非结构性标签和支持的 EXIF 项；对于不支持的指针结构明确拒绝。某些应用未必能读取 BigTIFF 中的 EXIF，目标软件须实际验证。输入中已缺失的数据无法恢复。文件大小相近不表示与历史文件逐字节相同。请先用少量文件测试，并保存输入原件。

命令行可使用 `--direction to_big_tiled`，需要 `--output-dir`。生成的报告包含本机文件路径和校验值，应由使用者本地保管。
