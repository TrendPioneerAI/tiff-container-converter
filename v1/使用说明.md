# BigTIFF 转普通 TIFF 工具

版本：1.0.0  
适用系统：Windows 10/11 64位  
程序：`BigTIFF_to_ClassicTIFF.exe`

## 用途

将可以安全放入4 GiB以内的 BigTIFF（版本43）转换成 Classic TIFF（版本42），用于解决 Windows 照片查看器等只支持普通 TIFF 的软件无法打开 BigTIFF 的问题。

本工具不是图像重编码器。它直接复制源文件中的原始 Tile/Strip 图像块，不执行解码、重采样、颜色变换、位深转换或重新压缩。

## 双击使用

1. 双击 `BigTIFF_to_ClassicTIFF.exe`。
2. 选择输入 BigTIFF 文件。
3. 选择输出普通 TIFF 位置。默认文件名为“原名-classic.tif”。
4. 点击“开始安全转换”。
5. 等待界面显示“转换及验证完成：PASS”。
6. 输出 TIFF 同目录会生成一个 `.validation.json` 验证报告。

程序不会覆盖输入文件。若目标文件已存在，会再次询问是否替换。

## 命令行使用

```powershell
BigTIFF_to_ClassicTIFF.exe "输入.tif" -o "输出-classic.tif"
```

允许替换已存在的输出文件：

```powershell
BigTIFF_to_ClassicTIFF.exe "输入.tif" -o "输出-classic.tif" --overwrite
```

默认进行完整回读验证。`--no-verify` 可以跳过回读，但不建议在生产交付中使用。

## 会保留的内容

- Tile/Strip 图像块原始字节；
- 像素尺寸、位深、颜色解释、采样格式；
- 压缩数据本身与压缩方式；
- 瓦片或条带组织；
- GeoTIFF坐标标签；
- ImageDescription、Software、相机字段及其他可由普通TIFF表达的标签；
- 多个主IFD页面及内部金字塔（前提是没有额外SubIFD指针结构）。

验证报告分别计算图像块和非结构性元数据的SHA-256。如果任意一项不一致，结果会标为 `FAIL`。

## 必然发生的结构变化

- TIFF版本号：43变为42；
- 文件头：BigTIFF结构变为Classic TIFF结构；
- IFD计数、条目和下一IFD指针由64位结构变为32位结构；
- TileOffsets或StripOffsets重新计算并写成32位LONG；
- 文件大小通常会略微减小。

这些变化只涉及文件容器寻址，不改变图像内容和业务元数据。

## 安全限制

出现下列情况时，工具会拒绝转换：

- 预计输出达到或超过Classic TIFF的4 GiB上限；
- 单个图像块或标签值不能用32位Classic TIFF表达；
- 文件包含需要重定位但当前工具不能安全处理的SubIFD、ExifIFD、GPSIFD等指针；
- TIFF目录损坏、图像块越界、偏移/长度数量不匹配；
- 输入已经是普通TIFF；
- 输出路径与输入路径相同。

工具以拒绝输出为优先，不会在无法证明无损的情况下生成“看似成功”的文件。

## 260401035598.tif实测结果

- 输入：BigTIFF、1,292,187,272字节；
- 输出：Classic TIFF、1,292,160,840字节；
- 尺寸：31520×13440；
- RGB、8 bit、无压缩、256×256瓦片；
- 22个标签全部保留；
- 21个标签的类型、数量和原始值完全不变；
- TileOffsets按Classic TIFF要求重新计算；
- 图像块SHA-256前后一致；
- 非结构性元数据SHA-256前后一致；
- Windows WIC：原文件无法解码，转换后文件成功解码。

详细结果见 `260401035598-classic.validation.json`。

## 实现依据

- [LibTIFF BigTIFF规范](https://libtiff.gitlab.io/libtiff/specification/bigtiff.html)：BigTIFF将版本号从42改为43，并使用64位IFD和偏移；除此之外与Classic TIFF采用相同的图像与标签模型。
- [LibTIFF tiffcp官方说明](https://libtiff.gitlab.io/libtiff/tools/tiffcp.html)：默认写出Classic TIFF，并以不改变图像数据内容为目标。
- [GDAL GeoTIFF驱动说明](https://gdal.org/en/stable/drivers/raster/gtiff.html)：Classic TIFF受4 GiB限制，BigTIFF用于64位偏移和更大文件。
